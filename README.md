# 📘 Day 1 – Variables & Arguments

## 🔹 Overview
- **Variables** → Store and reuse data inside workflows.  
- **Arguments** → Pass data between workflows to make them modular and reusable. 
- Shortcut to create variable → **Ctrl + K**.  

---

## 🔹 Why Use Arguments?
- To **share data** between workflows.  
- To **control input and output** of workflows.  
- To **avoid hard‑coding values** and make processes dynamic.  
- To **improve clarity** by defining expected inputs and outputs.
